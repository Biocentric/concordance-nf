# Synthetic test cohort

Generated by [`tests/make_fixture_vcfs.py`](../../tests/make_fixture_vcfs.py).
Seven single-sample VCFs over 4000 synthetic biallelic sites at MAF 0.5, with a
deliberately broken identity structure:

| Pair | Declared | Genotypes | Expected verdict |
| --- | --- | --- | --- |
| `s_a` / `s_b` | same subject `P1` | identical | `CONFIRMED_MATCH` |
| `s_c` / `s_e` | subjects `P2` / `P4` | identical | `UNEXPECTED_DUPLICATE` |
| `s_f` / `s_g` | same subject `P5` | independent | `SAMPLE_SWAP` |
| the other 18 pairs | distinct subjects | independent | `CONFIRMED_DISTINCT` |

No human data. Sites sit 20 bp apart purely to keep `ref.fasta` small enough to
commit — somalier treats sites as independent, so spacing affects nothing.

Regenerate with:

```bash
python3 tests/make_fixture_vcfs.py assets/test_data
```

Note the generator writes absolute paths into `samplesheet.csv`; rewrite the
`alignment` column to bare filenames afterwards so the sheet stays portable
(the pipeline resolves samplesheet-relative paths).
